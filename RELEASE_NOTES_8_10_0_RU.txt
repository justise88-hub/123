PS GuardPRO 8.10.0

Брендовая версия на базе PS PassMaster PRO 8.9.0.

Изменения этой поставки:
- новое название продукта: PS GuardPRO;
- обновлены отображаемое имя приложения, сведения о программе, диагностические метаданные и тексты запуска;
- обновлены имена EXE, папок сборки, установщика и ярлыков;
- добавлен подробный GitHub Actions workflow в .github/workflows/ci.yml;
- добавлено руководство по фирменному стилю: BRAND_GUIDE_RU.md;
- сохранена графитно-янтарная палитра;
- пользовательские данные и структура базы не мигрируются и не переименовываются.

Ограничения:
- GitHub workflow требует успешной проверки в репозитории пользователя;
- физическая печать и работа с контроллером СКУД должны проверяться на целевом оборудовании;
- переименование не означает появления новых аппаратных интеграций.
