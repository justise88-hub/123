# PSVMS — доработка навигации

В этой версии выполнены изменения боковой навигации и переходов между основными разделами.

## Что изменено

- «Настройки» теперь полноценный пункт-страница бокового меню, а не отдельное действие. Активный пункт подсвечивается, заголовок и центральная страница синхронизируются.
- Страницы получили постоянные внутренние идентификаторы. Перетаскивание пунктов меню больше не должно путать их с индексами страниц `QStackedWidget`.
- Пользовательский порядок страниц сохраняется в `QSettings` (`ui/navPageOrder`) и восстанавливается при следующем запуске.
- Состояние свёрнутой/развёрнутой панели теперь действительно восстанавливается из `ui/navExpanded`.
- Скрытие пунктов по роли и получение кнопок страницы работают по постоянному ID страницы, а не по её текущей позиции в меню.
- Ctrl+1…Ctrl+4 ведут в соответствующие разделы; голосовая команда «настройки» использует тот же маршрут навигации.
- Действие «Архив» остаётся отдельной командой и не меняет выбранную страницу мониторинга.
- Сохранены существующая цветовая схема, значки, анимация активной подсветки и визуальный стиль левого меню.

## Ограничения проверки

Исходники и ZIP проверены на целостность. Конфигурация сборки в этой среде не завершилась: отсутствует Qt 6 SDK (`Qt6Config.cmake`). Поэтому успешная компиляция, запуск и проверка переходов в Windows пока не подтверждены.

## Дополнительная доводка навигации

- Последний открытый раздел запоминается сразу при переходе и восстанавливается при следующем запуске.
- Перед восстановлением проверяются права пользователя и доступность Pro-раздела; при отсутствии доступа открывается «Главная».
- Состояние свёрнутой/развёрнутой панели записывается сразу при переключении, а не только при закрытии программы.
- Порядок страниц синхронизируется с настройками после перетаскивания.

## Дополнительная проверка навигации

- Раздел «События» скрывается при запуске в редакции без Pro-доступа; при активации Pro он снова показывается. Это согласует видимость пункта меню с проверками доступа в горячих клавишах и голосовом управлении.
- Исправлена упаковка исходников в GitHub Actions: из списка удалён отсутствующий `REDESIGN_NOTES_RU.md`, а перед упаковкой добавлена проверка существования каждого входного пути. Это предотвращает падение шага `Compress-Archive` из-за отсутствующего файла.
- Проверка списка файлов workflow: все 14 входных путей существуют.

## Дополнительная защита Pro-раздела

- При окончании срока Pro-лицензии раздел «События» скрывается.
- Если в момент окончания лицензии пользователь находился в «Событиях», приложение переводит его на «Главная».
- При завершении временного Pro-сеанса применяется то же поведение.

## Единый шрифт левого меню

- Для пунктов разделов, нижних действий и кнопки пользователя установлен единый Segoe UI, 10 pt, DemiBold.
- Убрано автоматическое уменьшение размера шрифта отдельных подписей: длинный текст получает подсказку, но не меняет типографику остальных пунктов.
- Цвета, фон, подсветка активного пункта, иконки и геометрия меню не менялись.
- Логотип PSVMS оставлен отдельным фирменным заголовком, а не пунктом меню.
