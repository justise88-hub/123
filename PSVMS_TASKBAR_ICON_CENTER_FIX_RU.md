# PSVMS — центрирование значка приложения

- Перерисован `PSVMS.ico` с оптическим центром камеры по вертикальной оси значка.
- Обновлён `assets/psvms_taskbar.png`, который подключён в `branding.qrc` и используется как Qt window icon для приложения и диалогов.
- Сохранены тёмная подложка и бирюзовый фирменный цвет.
- В ICO включены размеры 16, 24, 32, 48, 64, 128 и 256 px, чтобы Windows выбирала подходящий ресурс для панели задач, ярлыков и разных масштабов.
- `app_icon.rc` и `create_shortcuts.ps1` уже ссылаются на `PSVMS.ico`, поэтому отдельные изменения этих файлов не требуются.

Проверена структура ICO и PNG. Проверка фактического отображения на панели задач Windows требует запуска собранного EXE на Windows; также Windows может кэшировать старый значок ярлыка, поэтому после обновления сборки ярлык следует пересоздать или обновить кэш значков.
