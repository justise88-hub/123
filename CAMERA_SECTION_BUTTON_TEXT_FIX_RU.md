# Исправление подписей кнопок раздела «Камеры»

- Панель управления разделена на отдельные строки: добавление/редактирование, действия с группами, удаление камер, поиск и управление записью.
- Длинные подписи «Добавить устройство», «Переименовать группу» и «Удалить группу» больше не конкурируют за ширину в одной строке.
- Для кнопок заданы минимальные ширины и высота, чтобы текст не обрезался при обычном изменении размеров окна.
- Убраны многоточия из подписей кнопок переименования и удаления группы; многоточия остаются в диалоговых/контекстных действиях, где обозначают открытие следующего окна.
- Обработчики нажатий и функции кнопок не менялись.

Изменён файл: `modules/app_pages.inc`.
