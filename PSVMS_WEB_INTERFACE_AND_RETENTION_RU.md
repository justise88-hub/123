# Веб-интерфейс устройств и оценка срока хранения

## Веб-интерфейс

В настройках камеры укажите URL веб-панели устройства (`http://...` или `https://...`). В разделе «Устройства» выберите устройство и нажмите «Веб-интерфейс» либо используйте контекстное меню. Если URL не задан, PSVMS подставит HTTP-адрес хоста из RTSP-ссылки. Страница открывается во внешнем браузере; авторизация выполняется самим устройством. PSVMS не передаёт пароль в URL.

## Автополучение параметров HiWatch / Hikvision

В настройках камеры есть команда «Получить кодек и битрейт автоматически (ISAPI)…». Она делает запрос `GET /ISAPI/Streaming/channels/101` к веб-адресу устройства или HTTP-хосту из RTSP-ссылки. При HTTP Digest/Basic challenge используются логин и пароль из RTSP URL. Поддерживаются распознаваемые поля типа видеокодека и `constantBitRate` / `vbrUpperCap` / `maxBitrate` в XML-ответе. Значения после получения нужно проверить и сохранить вручную.

Это best-effort совместимость для HiWatch/Hikvision. Разные модели и прошивки могут использовать другие endpoint, требовать HTTPS/другой порт, не отдавать ISAPI или возвращать верхний предел VBR вместо среднего битрейта. EZVIZ не гарантирует ISAPI; для таких устройств используйте ONVIF/RTSP и ручные параметры. Если запрос не удался, приложение не ломает настройки и оставляет ручной ввод.

Учётные данные не сохраняются отдельными полями: для ISAPI они извлекаются из RTSP URL только на время запроса. Если URL не содержит логин/пароль, endpoint может ответить 401.

## Оценка хранения

Для каждой камеры задайте битрейт основного потока в кбит/с и кодек. Расчёт показывает расход каждой группы в ГБ/сутки и общий прогноз хранения на свободном месте диска, где расположен локальный архив PSVMS. При общем HDD срок хранения одинаков для всех групп, поскольку они используют одну общую ёмкость; отдельные строки групп показывают вклад в расход. Формула: `байты_в_секунду = суммарный_битрейт_кбит_с * 1000 / 8`.

Это расчётная оценка, не чтение фактического HDD регистратора. Реальный срок зависит от VBR, аудио, движения, расписания, количества потоков, служебных данных и квот NVR. Кодек отображается для справки: нельзя дополнительно приписывать H.265 фиксированный процент экономии, если уже указан фактический битрейт.
