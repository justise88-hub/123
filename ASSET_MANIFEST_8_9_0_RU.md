# Синхронизация фотографий и шаблонов — 8.9.0

## Назначение
Модуль добавляет манифест для фотографий (`jpg`, `jpeg`, `png`, `webp`, `bmp`) и шаблонов Magicard (`card`). Каждый файл идентифицируется относительным путём и SHA-256. Серверный транспорт использует существующий HTTPS API и хранит бинарные файлы по SHA-256.

## Запуск
1. Сделайте резервные копии базы и каталога файлов.
2. Убедитесь, что главный компьютер запускает LAN-сервер и TLS настроен.
3. На рабочей станции задайте токен в переменной окружения `PSPASSMASTER_SYNC_TOKEN`.
4. Выполните `python run_asset_sync.py --db <путь-к-БД> --assets <каталог-файлов> --url https://<сервер>:8765 --ca <CA-файл> --scan`.
5. Повторяйте команду для следующего обмена; для повторного обмена без полного сканирования можно убрать `--scan`.

## Защита данных
- Поддерживаются только указанные расширения, размер файла — от 1 байта до 25 МиБ.
- Символические ссылки пропускаются; относительные пути проверяются на выход за пределы каталога.
- Перед загрузкой и после скачивания проверяется SHA-256.
- Скачивание выполняется во временный файл с атомарной заменой только если целевого файла ещё нет.
- Если по тому же пути уже лежит другое содержимое, локальный файл сохраняется, конфликт записывается в `sync_asset_conflicts`.
- Удалённое удаление не удаляет локальный файл автоматически.

## Ограничения релиза
Это ручной CLI-инструмент. Он не меняет `employees.photo_path`, не активирует скачанные шаблоны и не запускается в фоне из графического интерфейса. Для рабочего процесса требуется последующая интеграция в GUI с экраном подтверждения конфликтов. Не использовать общую SQLite-базу по сетевой папке.
