# Установка PS GuardPRO 8.10.0

1. Распакуйте архив в локальную папку Windows.
2. Установите Python 3.11 x64 и включите Add Python to PATH.
3. Запустите `build_windows.bat` — скрипт установит зависимости и соберёт `dist\PS_GuardPRO\PS_GuardPRO.exe`.
4. Для установщика установите Inno Setup 6 и запустите `build_installer.bat`; сценарий `PS_GuardPRO.iss` создаст Setup в `installer_output`.
5. Для ярлыков запустите `create_shortcuts.ps1` из папки собранного приложения.

Пользовательская база и рабочие данные остаются в прежнем каталоге `%LOCALAPPDATA%\PSPassMasterPRO`, чтобы брендовый переход не потерял существующие записи. Переносить или удалять эту папку при обновлении нельзя.

Печать выполняется штатными средствами Magicard HUB. Наличие реального подключения к контроллерам СКУД зависит от отдельной поддерживаемой интеграции.
