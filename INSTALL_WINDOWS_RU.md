# Установка PS PassMaster PRO 3.6.0 в Windows

1. Установите Python 3.11 или 3.12 x64.
2. Распакуйте архив в обычную папку, например `C:\Build\PS_PassMaster_PRO`.
3. Запустите `build_windows.bat`. Скрипт создаст виртуальное окружение и соберёт `dist\PS_PassMaster_PRO\PS_PassMaster_PRO.exe`.
4. Для установщика установите Inno Setup 6 и запустите `build_installer.bat`. Получится `installer_output\PS_PassMaster_PRO_3.6.0_Setup.exe`.
5. В установщике можно включить ярлык на рабочем столе; ярлык в меню «Пуск» создаётся автоматически.

Установка выполняется в профиль пользователя и не требует прав администратора. Magicard HUB и драйвер принтера устанавливаются отдельно. Печать выполняется штатными средствами Magicard HUB.

Пользовательская база и настройки прежних выпусков сохраняются в прежнем каталоге `%LOCALAPPDATA%\PSrazmerPRO`, чтобы ребрендинг не приводил к потере данных. Перед обновлением рекомендуется сделать резервную копию.
